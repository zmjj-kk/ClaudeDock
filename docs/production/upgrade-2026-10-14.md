## 架构与信任边界

本地 token 为 `~/.kama/ipc-<port>.token`，所有者必须为当前用户且权限 0600；
显式 `KAMA_IPC_TOKEN` 适用于容器/远程部署。token 代表单个可信 daemon 用户，
不是多租户 RBAC；拥有 token 的客户端能发起该用户的任务。远程监听还要求
`KAMA_ALLOW_REMOTE=1` 和 TLS，或显式受信代理声明。

审批只发送给发起连接；回复须来自同一连接。“本会话允许”仅缓存同一规范输入，
3600 秒过期，断线清理未决审批。历史回放不能响应旧审批。工具 JSON Schema 在
授权前校验；外部 $ref 与可能失控的正则模式被拒绝。Shell 默认隔离失败就拒绝执行；
模型不能通过参数关闭隔离。文件操作通过目录描述符与 O_NOFOLLOW 约束 workspace。
RAG/MCP/Skill 内容作为不可信数据；工具白名单、预算与审批仍由本地代码控制。

运行过程为 queued→running→waiting_approval/cancelling→终态。监督池管理
前台运行、子任务及整合作业；启动失败/关闭通过 AsyncExitStack 逆序回收。
外部流已输出内容后不盲目重试；非幂等工具未知结果记录 unknown，恢复时先查证。

## 数据字典与告警建议

关联字段：run_id、session_id、parent_run_id、tool_use_id、operation_id；step 在步骤事件中。
事件 sequence 只保证每 run 的有序去重，不是全局序号。敏感正文不作指标标签。
Span：agent.run / llm.chat / tool.invoke / rag.search / mcp.request；
耗时单位 ms，outcome success/failed，指标只使用有界 tool_name/model/method 标签。
Trace 丢弃计数表示队列饱和；unknown operation 表示需要人工确认实际副作用。

建议告警：健康探针连续 3 次失败；持久化失败任意一次；Trace drop 持续增长；
审批/请求等待超过预算；pending jobs 连续 5 分钟达到配置上限；
同类操作 P95 超过基准三倍持续 10 分钟。阈值是待生产校准建议，当前未部署告警。

运维与回滚命令见 [运维手册](operations.md)。
